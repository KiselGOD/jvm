# Общая структура 3х адресной ВМ с машинным словом 64 бит

## 1. Реализация регистровая

- 29 регистра общего назначения
- 1 регистр для флага условий
  - `FLAG_ZERO` — результат операции равен 0
  - `FLAG_SIGN` — знак результата операции
  - `FLAG_CARRY` — при сложении двух беззнаковых чисел произошёл перенос за пределы разрядности машинного слова
    (когда при сложении из самого старшего бита вылезает единица наружу или при вычитании нужен заём снаружи)
  - `FLAG_OVERFLOW` — выход за знаковый диапазон (когда расчёты залезли на знаковый бит или просто выход за знаковый диапазон)
  - `FLAG_NAN` — результат операции несравним ни с чем, нужен для исключений типа `0.0 / 0.0` или `sqrt(-1.0)` (
    Не прерывает длинные вычисления тк не исключение, любая арифметическая операция с NaN тоже даёт NaN)
- 1 регистр-счётчик команд
- 1 регистр-счётчик стека

## 2. Набор команд

1. `STP` — аргументов нет — остановка выполнения программы
2. `MV` — `rd` (номер регистра), `rs` (номер регистра) — копирование значения из регистра `rs` в регистр `rd`
3. `LI` — `rd` (номер регистра), `imm` (целое число) — загрузка целого числа `imm` в регистр `rd`
4. `LF` — `rd` (номер регистра), `imm` (вещественное число) — загрузка вещественного числа `imm` в регистр `rd`
5. `LK` — `rd` (номер регистра), `idx` (индекс в секции констант) — загрузка константы по индексу `idx` из секции констант в регистр `rd`
6. `JMP` — `target` (смещение в секции кода) — безусловный переход счётчика команд `PC` на `target`
7. `JZ` — `rs` (номер регистра), `target` (смещение в секции кода) — переход счётчика команд `PC` на `target`, если значение в регистре `rs` равно нулю
8. `JNZ` — `rs` (номер регистра), `target` (смещение в секции кода) — переход счётчика команд `PC` на `target`, если значение в регистре `rs` не равно нулю
9. `ADD` — `rd` (номер регистра), `rs1` (номер регистра), `rs2` (номер регистра) — сложение целых чисел из регистров `rs1` и `rs2` с записью результата в регистр `rd`
10. `SUB` — `rd` (номер регистра), `rs1` (номер регистра), `rs2` (номер регистра) — вычитание целого числа из регистра `rs2` из целого числа в регистре `rs1` с записью результата в регистр `rd`
11. `MUL` — `rd` (номер регистра), `rs1` (номер регистра), `rs2` (номер регистра) — умножение целых чисел из регистров `rs1` и `rs2` с записью результата в регистр `rd`
12. `DIV` — `rd` (номер регистра), `rs1` (номер регистра), `rs2` (номер регистра) — деление целого числа из регистра `rs1` на целое число из регистра `rs2` с записью результата в регистр `rd`
13. `MOD` — `rd` (номер регистра), `rs1` (номер регистра), `rs2` (номер регистра) — взятие остатка от деления целого числа из регистра `rs1` на целое число из регистра `rs2` с записью результата в регистр `rd`
14. `NEG` — `rd` (номер регистра), `rs` (номер регистра) — смена знака целого числа из регистра `rs` с записью результата в регистр `rd`
15. `FADD` — `rd` (номер регистра), `rs1` (номер регистра), `rs2` (номер регистра) — сложение вещественных чисел из регистров `rs1` и `rs2` с записью результата в регистр `rd`
16. `FSUB` — `rd` (номер регистра), `rs1` (номер регистра), `rs2` (номер регистра) — вычитание вещественного числа из регистра `rs2` из вещественного числа в регистре `rs1` с записью результата в регистр `rd`
17. `FMUL` — `rd` (номер регистра), `rs1` (номер регистра), `rs2` (номер регистра) — умножение вещественных чисел из регистров `rs1` и `rs2` с записью результата в регистр `rd`
18. `FDIV` — `rd` (номер регистра), `rs1` (номер регистра), `rs2` (номер регистра) — деление вещественного числа из регистра `rs1` на вещественное число из регистра `rs2` с записью результата в регистр `rd`
19. `FMOD` — `rd` (номер регистра), `rs1` (номер регистра), `rs2` (номер регистра) — взятие остатка от деления вещественного числа из регистра `rs1` на вещественное число из регистра `rs2` с записью результата в регистр `rd`
20. `FNEG` — `rd` (номер регистра), `rs` (номер регистра) — смена знака вещественного числа из регистра `rs` с записью результата в регистр `rd`
21. `I2F` — `rd` (номер регистра), `rs` (номер регистра) — преобразование целого числа из регистра `rs` в вещественное с записью результата в регистр `rd`
22. `F2I` — `rd` (номер регистра), `rs` (номер регистра) — преобразование вещественного числа из регистра `rs` в целое с записью результата в регистр `rd`
23. `EQ` — `rd` (номер регистра), `rs1` (номер регистра), `rs2` (номер регистра) — сравнение целых чисел из регистров `rs1` и `rs2` на равенство с записью 1 или 0 в регистр `rd`
24. `LT` — `rd` (номер регистра), `rs1` (номер регистра), `rs2` (номер регистра) — сравнение целого числа из регистра `rs1` на меньше, чем в регистре `rs2`, с записью 1 или 0 в регистр `rd`
25. `LE` — `rd` (номер регистра), `rs1` (номер регистра), `rs2` (номер регистра) — сравнение целого числа из регистра `rs1` на меньше или равно, чем в регистре `rs2`, с записью 1 или 0 в регистр `rd`
26. `FEQ` — `rd` (номер регистра), `rs1` (номер регистра), `rs2` (номер регистра) — сравнение вещественных чисел из регистров `rs1` и `rs2` на равенство с записью 1 или 0 в регистр `rd`
27. `FLT` — `rd` (номер регистра), `rs1` (номер регистра), `rs2` (номер регистра) — сравнение вещественного числа из регистра `rs1` на меньше, чем в регистре `rs2`, с записью 1 или 0 в регистр `rd`
28. `FLE` — `rd` (номер регистра), `rs1` (номер регистра), `rs2` (номер регистра) — сравнение вещественного числа из регистра `rs1` на меньше или равно, чем в регистре `rs2`, с записью 1 или 0 в регистр `rd`
29. `IN` — `rd` (номер регистра) — чтение целого числа из стандартного ввода и запись его в регистр `rd`
30. `FIN` — `rd` (номер регистра) — чтение вещественного числа из стандартного ввода и запись его в регистр `rd`
31. `PR` — `rs` (номер регистра) — вывод целого значения из регистра `rs` в стандартный вывод
32. `FPR` — `rs` (номер регистра) — вывод дробного значения из регистра `rs` в стандартный вывод
33. `ALLOC` — `rd` (номер регистра), `rs_size` (номер регистра) — выделение блока памяти в куче размером из регистра `rs_size` байт и запись offset начала блоков в регистр `rd`
34. `FREE` — `rs_addr` (номер регистра) — освобождение блока памяти в куче по offset из регистра `rs_addr`
35. `LOAD64` — `rd` (номер регистра), `offset` (смещение в байтах) — чтение 64-битного значения из кучи по `offser` из регистра `rs_addr` со смещением `offset` в регистр `rd`
36. `STORE64` — `rs_addr` (номер регистра), `offset` (смещение в байтах), `rs_val` (номер регистра) — запись 64-битного значения из регистра `rs_val` в кучу по адресу из регистра `rs_addr` со смещением `offset`

## 3. Структура инструкции

```text
31                                              11 10             6 5           0
+-------------------------------------------------------------------------------+
| 21 bits: imm/offset/target                      | 5 bits: r1     | 6 bits: op |
+-------------------------------------------------+----------------+------------+
```

Это операции `LK`, `LI`, `LF`, `JMP`, `JZ`, `JNZ`, `LOAD64`, `STORE64`.

```text
31                21 20          16 15          11 10             6 5           0
+-------------------+--------------+--------------+----------------+------------+
| 11 bits: reserved | 5 bits: r3   | 5 bits: r2   | 5 bits: r1     | 6 bits: op |
+-------------------+--------------+--------------+----------------+------------+
```

Это операции `ADD`, `SUB`, `MUL`, `DIV`, `MOD`, `FADD`, `FSUB`, `FMUL`, `FDIV`, `FMOD`, `EQ`, `LT`, `LE`, `FEQ`, `FLT`, `FLE`.

```text
31                  16 15          11 10             6 5           0
+---------------------+--------------+----------------+------------+
| 16 bits: reserved   | 5 bits: r2   | 5 bits: r1     | 6 bits: op |
+---------------------+--------------+----------------+------------+
```

Это операции `STP`, `MV`, `NEG`, `FNEG`, `I2F`, `F2I`, `IN`, `FIN`, `PR`, `FPR`, `ALLOC`, `FREE`.

## 4. Память

Будет состоять из 4 областей:

1. Область с кодом (`std::vector<uint32_t> code_area`)
   - Размер загружается из метаданных исполняемого файла, выделяется перед каждый запуском кода.
   - `PC`-регистр — это индекс инструкции (отсчёт с 0 до `code_area.size() - 1`).
   - Во время исполнения `code_area` редактироваться не может и не должен.
2. Область констант (`std::vector<uint64_t> const_area`)
   - Размер определяется из метаданных исполняемого файла.
   - Может хранить и числа (`double`/`int64`/`uint64`), и текст ASCII (по 8 символов по 8 бит на ячейку).
   - `idx` — это индекс в массиве (отсчёт с 0 до `const_area.size() - 1`).
   - Во время исполнения `const_area` редактироваться не может и не должен.
3. Стек вызовов функций, локальных переменных, сохранённых регистров и временных значений (`std::vector<uint64_t> stack`)
   - Размер 1024 * 1024 байт, те 131 072 слота типа `uint64` (8 байт).
   - `PS`-регистр — это индекс указателя в стеке (отсчёт с 0 до `stack.size() - 1`).
   - `PS == stack.size()` — переполнение.
4. Куча
   - Размер 16 * 1024 * 1024.
   - `addres = 0` — это `NULL`.
   - Любой адрес блока `addr` и смещение `offset` проверяются на попадание в диапазон `[8, heap.size())`, а доступ по `LOAD64` / `STORE64` — на `addr + offset + 8 <= heap.size()` (с учётом переполнения при сложении `uint64_t`).
